# A20 AEI R9 reproducible rebuild

Status: prospective design and implementation preparation. No new calibration or confirmation outcomes have been generated. The earlier ChatGPT R9 progress is a design reference, not recovered execution evidence.

The frozen R8 archive is retained. This branch will implement and evaluate cross-task evidence reuse when inspection requirements change. Numerical localization gains must be attributed to the executed policies, while evidence reuse, update cost and invalidation correctness are measured separately.

## Research questions

1. Can explicitly compiled task-event relations support sound evidence reuse across acquisition, spatial association and timely reporting requirements?
2. Which requirement relaxations preserve the executor and population, and which producer, timing or distribution changes require recertification?
3. How do semantic reuse and cached direct recertification compare in supported requests, actual record evaluations, preparation cost and repeated-query time?
4. Can an independently implemented, fully validated procedural version achieve the same numerical and authorization outcomes? Equal or better procedural results will be retained.

## Preservation and synchronization

Code, drafts, protocol versions, run logs and manifests will be committed to this branch. Large raw inputs and result archives will be uploaded as stage-specific GitHub release assets with SHA256 manifests. A checkpoint records whether its remote upload was verified. Local files are not described as remotely backed up until GitHub readback succeeds.

Original R8 predictors, meshes, source replacement and replay are retained as dependencies. The Windows native-library adapter, fresh input generation and camera/task modules are separate new components. R8 risk cards do not certify new optical tasks.

The proposed protocol is in `protocol/PROSPECTIVE_DESIGN_CN.md`. It remains a draft until pilot checks, numerical and statistical audits, and the method/data-dependency hash freeze are complete.
